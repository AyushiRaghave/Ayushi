# Promptless — validation plan

## Research question

Does task-specific guidance help people get to a usable AI-assisted deliverable with less effort than their current way of working?

## Hypotheses

1. People can identify the right workflow from the task description without needing to understand prompt terminology.
2. Focused context questions reduce missing information and avoidable prompt iterations.
3. The task-specific output contract produces deliverables that require less substantial rework.
4. Saved work and workflow hand-off make repeat tasks more convenient.

## Participants

Recruit 8–12 people for an initial formative study:
- 3–4 occasional AI users.
- 3–4 frequent AI users.
- 2–4 solo professionals or small-business operators who use AI for recurring work.

This is a usability and discovery sample, not a statistically representative market study.

## Tasks

Ask each participant to complete two comparable tasks:
- Write a context-sensitive professional email.
- Turn a loose request into an actionable brief.
- Diagnose a realistic work blocker and choose a next test.
- Compare two options using supplied source material.

Counterbalance task order where practical. Let participants use their normal AI workflow for one task and Promptless for the other.

## Observe

- How long it takes to choose a workflow.
- Which fields cause hesitation or confusion.
- What information participants provide without prompting.
- Whether the output is usable for its intended purpose.
- What they edit, reject or regenerate.
- Whether they would save or reuse the result.

## Measures

| Measure | Definition |
|---|---|
| Task completion | Participant reaches a deliverable that meets the stated task goal |
| Time to usable result | Time from task start to participant acceptance |
| Substantial rework | Changes required to make the result fit the task, excluding minor preference edits |
| Workflow abandonment | Participant stops before receiving or using a result |
| Context friction | Fields skipped, misunderstood or repeatedly corrected |
| Reuse intent | Participant chooses to save or reuse the workflow for a similar future task |

## Method

1. Give the participant a realistic scenario and the same source information in both conditions.
2. Ask them to think aloud without steering them toward a preferred workflow.
3. Record task time and observable friction with consent.
4. Ask the participant to rate usefulness, effort and confidence after each task.
5. Interview them about what they would keep, remove or change.
6. Compare Promptless against their baseline workflow.

## Decision rules

- If users cannot identify the correct workflow quickly, improve task discovery before adding more tools.
- If users abandon on input fields, remove or defer low-value questions.
- If outputs require substantial rework, improve the task contract and connected workflow before polishing the interface.
- If users prefer their existing AI workflow, identify the specific advantage Promptless failed to provide.
- If users save and reuse context, invest in continuity; otherwise do not build a larger history system prematurely.

## Research safeguards

- Obtain informed consent.
- Do not ask participants to submit confidential employer or customer data.
- Do not use sensitive personal situations as test tasks for the Reflection workflow.
- Separate observed behaviour from participant opinions.
- Report sample size and limitations with findings.
